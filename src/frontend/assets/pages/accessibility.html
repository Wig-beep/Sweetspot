Accessibility statement for SweetSpot

Draft. The organisation that provides SweetSpot must check this statement, add its contact details and publish it. It describes SweetSpot version {{version}}.

SweetSpot is a learning tool for people on structured diabetes education. We want as many people as possible to be able to use it. For example, it is designed so that you can:

  • use it with a keyboard
  • use it with a screen reader
  • zoom in up to 400% without the text spilling off the screen
  • use it on a phone, tablet or computer, without scrolling sideways
  • use Windows high contrast mode

Charts have text descriptions, results are written out as well as drawn, and colours always come with words or line patterns.

How accessible SweetSpot is

We know some parts are not fully accessible:

  • In the charts, the legend can show or hide a change you tried, but only with a mouse or by touch, not with a keyboard. The results of every change are also in the day summary, and you can try a change again.
  • Exact values on the charts appear when you point at them with a mouse. The main values are written on the charts and in the day summary.
  • SweetSpot has not yet been tested with people who use assistive technology, or by an accessibility specialist.

Enforcement procedure

The Equality and Human Rights Commission (EHRC) is responsible for enforcing the Public Sector Bodies (Websites and Mobile Applications) (No. 2) Accessibility Regulations 2018 (the "accessibility regulations"). If you are not happy with how we respond to your complaint, contact the Equality Advisory and Support Service (EASS).

Technical information about this website's accessibility

SweetSpot is partially compliant with the Web Content Accessibility Guidelines version 2.2 AA standard, because of the non-compliance listed below.

Non-compliance with the accessibility regulations

Showing and hiding a change in the chart legend cannot be done with a keyboard. This fails WCAG 2.2 success criterion 2.1.1 (Keyboard). We plan to fix this.

How we tested SweetSpot

Every change to SweetSpot is checked automatically with axe-core for WCAG 2.2 AA problems, in Chrome and Safari, on computer and phone screen sizes, for the start page, a scenario with a change and the educator tools. Testing with screen readers, keyboard only, zoom and high contrast is planned before SweetSpot is offered to learners.
